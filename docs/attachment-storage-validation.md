日期：2026-09-19。开发基线：`60cc806`。

父文档导入、继续、接受候选和任务完成均不再自动登记或处理附件子来源。
附件字节与有序位置关系保存在既有 blob 和父 `ParseVersion` 中。文件扩展名
不决定是否保存；无法拆出文件载荷时保留原始对象并记录原因。DOCX profile

依赖审核输入。覆盖状态明确记为 `stored / attachment_stored_only`。旧自动
排队附件任务停止，历史子来源和任务记录保留。正文图片 OCR 规则不变。

## 自动回归

回归覆盖任意文件名/格式、原始对象回退、同名不同内容、同文件多位置与
表格位置、旧解析继续、候选接受、独立来源身份、父任务不派生子任务、
历史任务停止、清理保留附件、历史证据可读，以及旧展开正文的模型输入隔离。
父正文真实遗漏仍保持 partial；历史附件不消耗导航正文预算，也不重复计入
已有分析单元。显式处理子资料的云 OCR 恢复继续单独测试。
