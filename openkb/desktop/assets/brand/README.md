# UrltraKB brand resources

These original SVGs are copied unchanged from the maintainer-supplied OpenKB
desktop reference, `assets/brand/`, on 2026-09-08 for issue #12. The supplied
pure mark, application icon and monochrome variants are approved for reuse.
Original filenames identify their provenance; none contains the old wordmark.
The application pairs the pure mark with the display name **UrltraKB**.

The unchanged ICO is the reference's `desktop/src-tauri/icons/icon.ico`, exported
from the approved application mark. The frozen-build recipe uses it for the
executable icon; rebuilding distributions remains a separate acceptance step.

No reference checkout is required at runtime. These resources ship with the
Python package and are collected by the existing desktop packaging recipe.
Use the application icon for window/application identity, the pure mark on
neutral surfaces, and the monochrome marks where contrast requires them.
