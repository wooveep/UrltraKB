## 原因及统一覆盖

四项共因是来源证据在入口间丢失，消费侧以文本拼写重新认证结构：

| 问题 | 原因 | 当前处理 |
| --- | --- | --- |
| PPTX 提取不一致 | `.okpi` 直接调用旧 PDF 解析器，`body` 单独使用 `get_text()` | 新策略调用共享原生 PDF 提取，正文、表格、顺序、软蒙版一致；备注只负责独立关联 |
| 单元格误认证 | 控件被忽略，选项和段落被直接拼接 | 保留原文，未支持控件的值未确认；保留段落边界，区分空值与未知、部分读取 |
| PDF 字面 HTML 误认证 | 几何结果被降为普通文字，编译和问答重新解析所有标签 | 只接受提取阶段记录的表格区域；几何数为 0/1/1 的三种资料分别认证 0/1/1 |
| 图片位置与图注猜测 | 位置映射被页规范化丢弃，消费侧按同路径匹配和取首个 alt | 保留出现位置，搬移资产时同步调整坐标；选区按出现位置关联，图注只取明确记录 |

PPTX 旧路径早于 `88afc7fe`，属于未覆盖后续原生提取修复；其余认证行为涉及
后续新增的表格值、表格结构和图片绑定。图片部分还有早已存在的整页清单与
部分读取混用，不能把所有症状都归为某一新提交。原文存储完整不等于建树或
模型证据正确；本次同时检查提取、保存、建树输入和阅读投影。

`source_contract.py` 汇集来源角色与图片选区规则。格式适配负责提供证据；
共享读取在完整来源上判定，再映射选区；导入建树、编译、问答使用同一读取契约。
短 PDF 转换也复用分页提取。HTML 的格式适配保留原生表格，避免在进入共享规则前
丢掉控件和合并关系。编译和公开问答均支持一致的幻灯片分区读取。
投影只带所选内容及必要定位，不通过 `slide.body/notes` 元数据旁带未读正文。
正常编译计划的显式页坐标可以选择 `body`、`notes` 或全页；无法证明分区坐标的
组合在计划校验处拒绝。生成的图片包装保留独立范围，供建树排除其原文导航资格；
图片清单或生成的文件名不能把无正文幻灯片变成有文字的章节。

## 缓存与处理版本

保留旧 PDF、旧幻灯片、旧 HTML 的已知策略；旧缓存缺失时使用记录的解析器恢复，
不请求模型重建。新原生来源契约、HTML 转换及值规则进入新处理指纹。
PageIndex 本地版本精确固定为 `0.3.0.dev3+urltrakb.13`，提供契约坐标搬移与生成范围校验，
既有无位置契约的缓存沿用其记录的语义。没有迁移、批量更新或重处理入口的自动调用。

旧来源缺少几何或位置证明时保留原文、资产和原始身份，结构/图片位置为未确认；
不从原文补出证明。已有 `image_reference_spans` 可在原坐标域读取，旧 Office
单独冻结的正文不能继承整页坐标。图片出现身份保持页和原始 ordinal，
出现范围作为独立字段；同一资产的不同出现不会因路径相同而合并。
裸旧 Markdown 不新增图片角色，也不会因字面 `data:image` 示例要求重处理；
已有画廊和图片记录继续可读，当前阅读不覆写旧图片记录。

## 验证范围

新增回归涵盖控件、段落、空值、内联文本、Markdown/HTML 两种来源；
真实生成 PDF 的字面标签、真实网格与混合页；带合并单元格、隐藏标识、备注、
后绘制图片和半透明像素的幻灯片；超长页的公开问答预算截取；重复资产的不同出现；
资产搬移前后的表格坐标和受损缓存；旧策略的完整及范围读取。
跨入口反例同时覆盖裸旧 Markdown、编译计划的错误分区坐标，正例保留明确声明的
Markdown 图片绑定及旧画廊历史；原生幻灯片的无正文/有备注建树测试继续通过。

测试通过实际本地 PageIndex 建树、导入后保存的来源、编译窗口和公开问答工具观察结果。
模型使用注入的固定响应。原文和缓存字节不变断言用于锁定兼容行为。
