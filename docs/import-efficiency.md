# 按阶段控制文档导入的推理开销

文档导入先保留原件并解析，再建立原文导航，并在冻结原文证据上形成全局 `DocumentPlan`：每个范围进入页面主体、必要上下文、仅保留在来源的材料或具名待决项。计划接受后才生成页面，最后进行证据审核和必要的纠错。生成提示词区分当前证据与相邻背景，要求保留条件、例外、命令和参数；审核仍独立检查实际输出。

对于支持 `thinking` 和 `reasoning_effort` 控制的模型，可在知识库高级配置中分别控制各阶段。以下组合是 DeepSeek 的样本试验配置，尚未证明整流程提速，不作为推荐值或通用默认值。

```yaml
compilation_thinking: disabled
planning_thinking: enabled
planning_reasoning_effort: high
verification_thinking: enabled
verification_reasoning_effort: high
correction_thinking: enabled
correction_reasoning_effort: high
```

| 阶段 | 使用的控制 | 保留的检查 |
| --- | --- | --- |
| 原件接入、解析、OCR | 原有解析配置；不受上述主模型推理设置控制 | 文件完整性、原文位置、附件归属 |
| 导航结构与文档级 `DocumentPlan` W/S/T 规划 | `planning_*`，未设置时继承 `compilation_*` | 原文范围、累计计划、页面/上下文/来源专属/待决项覆盖 |
| 页面候选生成 | `compilation_*` | 计划页面成员覆盖、原文范围和输出结构 |
| 导航摘要核验、页面证据审核、遗漏依赖审核 | `verification_*` | 条件、例外、命令、数值及来源适用范围 |
| 被审核指出问题后的生成纠错 | `correction_*` | 修复后重新审核；不能直接发布纠错结果 |
| 可选的二次裁定 | `verification_adjudication_*` | 只有显式设置了不同于普通审核的参数，才有独立的更强裁定档位 |

关闭推理的请求不发送 `reasoning_effort`，即使配置中存在继承的值。该值仍保留在配置中，供启用推理的审核或纠错继承。未设置任何推理控制时，仍沿用模型提供方的默认行为。

提示词不把“相邻”当成事实关联，不允许将前提改写成操作目标，也不根据技术常识补全命令或解释效果。正式计划用原文范围和带依据范围的必要上下文组织页面，不增加事实关系；生成与审核分别遵守这些边界。必要上下文仍随请求传递，不能为减少 token 而删除真实前提。

推理关闭不等于免审核。有效 JSON、完整的 `covered` 数组或参数字符串匹配都不足以证明语义正确。审核未通过的内容按原有纠错、遗漏记录及发布规则处理，不因选择快速生成而放宽。

配置和提示词都参与分析与续做的有效性判定。配置修改不会改变已经启动的工作进程；后续任务采用新配置。更换提示词或有效模型参数后，受影响的旧分析可能需要重新执行，不能将旧结果当作新策略的实测结果。

比较方案时应从相同原件、解析设置和模型开始，使用隔离知识库并记录完整任务族（包括可解析附件）的请求、token、耗时、纠错、遗漏及最终发布内容。只看首次生成变快，不能代表整个导入流程更快；只统计成功请求也会漏掉重试与失败消耗。

《云平台整体恢复方案.docx》的首轮文档级试验中，连规划一起关闭推理后出现了更多拆分和页面，后续生成与审核请求明显增多。因此规划单独保留推理；最终效果需以完整任务族的实测结果判断。

四组完整任务族试验中，保留必要条件后的候选用时 15.77 分钟，基线 15.49 分钟，总 token 增加约 15.3%。更短的审核提示词也需要与推理档位配对评估：无推理、low 及现行 high 都在真实数值错误样本中发生过漏检；精简提示词配 high 的一次回放检出了该错误，却更慢。保留 high 不能消除此类风险，不能只按速度或推理档位选择。新增精简审核提示词仍为实验项，未替换运行时提示词。当前保留阶段配置能力及正式计划、生成提示词的边界补强；不自动修改既有知识库的推理配置，不将本轮候选宣传为已达到整流程提速。

固定请求回放还发现了输入端歧义：邻接原文的 128 字符窗口能恰好截断数值，却没有声明该数值尚未结束。现在所有证据读取路径保留原块长度，在规划、生成和审核所用的部分原文中注入 `source_window`（起止位置、总长度），并配套解释边界的提示词。原文字节和引用范围保持不变，模型应以完整原文核对边界值；窗口标记不会自动判定内容正确，也不能代替审核。

加入窗口标记后的第五轮完整任务族用时 9.82 分钟（基线 15.49 分钟），总 token 为 1,265,851（基线 1,270,981）。该轮仍有一份附件的完整主题未通过校验、未发布；基线的遗漏来自另一附件，质量结果并不等价。因此这里只记录单次观测提速约 36.6%，不据此自动启用快速配置或宣称质量验收通过。
